System Requirements & Compatibility

  • Case Support: 240mm radiator mounting space required
  • Power: Two 4-pin PWM fan headers + USB 2.0 header
  • Clearance: Check case radiator compatibility
  • Software: Windows 10/11 for iCUE software
  • Pump Power: 4-pin PWM or 3-pin connector
  • Installation: Compatible with most modern motherboards

Installation Guide

  • Install radiator in case before mounting
  • Apply mounting hardware to motherboard
  • Mount pump head with pre-applied thermal paste
  • Connect pump and fan PWM cables
  • Connect USB cable for RGB control
  • Install iCUE software for full functionality
