System Requirements & Compatibility

  • Case Clearance: 165mm CPU cooler height required
  • RAM Clearance: 32mm height limit with dual fans
  • Motherboard: Most ATX, mATX, ITX boards
  • Socket: Modern Intel and AMD sockets supported
  • Power: 4-pin PWM fan headers required
  • GPU Clearance: Check GPU length compatibility

Installation Notes

  • Verify case and RAM clearance before installation
  • Remove motherboard for easier installation
  • Apply thermal paste in rice grain-sized amount
  • Mount heatsink with even pressure
  • Connect PWM cables to CPU_FAN headers
  • Test system before final assembly
